# kit skill 优先路由规则

> 宿主记忆引用：`~/.claude/projects/*/memory/kit-priority-workflow.md`

---

## 规则摘要

当用户表达以下意图时，**优先使用 kit skill**，禁止直接手动创建文件或写代码：

| 场景 | 用户说法 | 优先命令 |
|---|---|---|
| 全新项目 | "我想做一个xxxxx"、"新建项目"、"从零开始"、"帮我开发" | `/kit-new` |
| 继续开发 | "继续做"、"接着做"、"按 kit 开发" | `/kit` → 检查状态 → 确认后 `/kit-run` |
| 状态检查 | "当前项目"、"检查状态"、"方向变了没"、"归档" | `/kit-status` |
| 执行开发 | "开始写代码"、"实现功能" | `/kit-run`（必须先经用户确认） |

---

## 宿主记忆同步

KIT 启动时，检查宿主记忆目录是否存在 `kit-priority-workflow.md`：

- **存在**：读取并应用用户自定义规则覆盖默认规则
- **不存在**：使用本文件定义的默认规则，并在首次使用时询问用户是否建立宿主记忆

---

## 默认路由规则

### 新建项目路由

```
用户说"我想做一个..."
    ↓
是否已建档？
    ├─ 是 → /kit-status 检查一致性 → 一致则继续 /kit-run，不一致则 brainstorm
    └─ 否 → /kit-new → brainstorm → 分类 → 三件套 → 用户确认 → /kit-run
```

### 状态检查路由

```
用户说"当前项目"、"检查状态"
    ↓
/kit-status
    ↓
读取 .plan/.kit → 状态简报 → 漂移检测
    ↓
无漂移 → "方向一致，可按计划继续"
有漂移 → 归档变更确认流程
```

### 执行开发路由

```
用户说"开始做"、"写代码"
    ↓
/kit-run 启动前检查清单（5项）
    ↓
全部通过 → 开始编码
任何不通过 → 停止，问用户
```

---

## 禁止行为

- ❌ 用户说"新建项目"时，直接 `mkdir` 或写文件
- ❌ 用户说"检查状态"时，直接浏览文件系统而不输出规范报告
- ❌ 跳过 `/kit` 的头脑风暴和确认门
- ❌ 用 "ok"、"好的" 代替用户明确"确认"

## 首次使用询问模板

首次检测到用户需要 kit skill 时，呈现：

```text
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📋 kit skill 优先规则
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

检测到你在{新建项目/检查状态}。

KIT Skills 提供标准化开发流程：
- /kit-new     → 全新项目建档（头脑风暴 + 三件套）
- /kit-status  → 项目状态检查（只读审计）
- /kit-run     → 执行开发（需用户确认）

是否使用 kit skills 流程？
- "确认" → 启动 kit 流程
- "跳过" → 本次不使用 kit，直接操作
- "了解更多" → 说明 kit skills 详细功能
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```
